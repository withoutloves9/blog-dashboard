# 블로그편집국 모바일 대시보드

네이버 블로그 글 제작 파이프라인을 폰에서 한 화면으로 보는 대시보드입니다.
빌드 도구·외부 CDN 없이 `index.html` 한 파일로 동작하며, GitHub Pages에서 바로 열립니다.

## 화면 구성

- **상단 요약** — 전체 / 발행완료 / 진행·대기 수치
- **진행 현황 막대그래프** — 전체 진행률(8단계 × 글 수 기준 누적 %) · 8단계별 분포 가로 막대 ·
  진행 중인 글별 단계 막대(2/8 = 25% 형태)
- **AI 라이브 스테이션** — 큐(Cue) · 부이(Vooy) · 뮤즈(Muse) · 키링(Keyring) · 자비스(Pickle)의
  현재 차례, 마지막으로 완료한 작업과 시각, 스케줄 실행 현황(15분 감시 · 매일 18:00 글감 발굴 · 매일 21:00 리포트)
- **발행 글 조회수 막대그래프** — 발행 11편의 네이버 블로그 조회수 가로 막대(총·평균·1위 배지),
  조회순 ↔ 최신순 정렬 토글, 줄을 누르면 해당 글로 이동
- **글 카드** — 제목 · 카테고리 · 상태 · 담당 · 8단계 슬림 프로그레스 · 할 일 한 줄.
  카드를 누르면 펼쳐지며 AI 진행 요약, 드라이브 이미지 링크, 제목 2안, 스레드 본문·첫 댓글 원클릭 복사가 나옵니다.
- **필터·검색** — 전체 / 진행·대기 / 발행완료 탭과 제목·선수·키워드 검색
- **테마** — 우상단 버튼으로 라이트 ↔ 다크 수동 전환 (선택은 브라우저에만 저장)

## 데이터

정적 HTML입니다. 노션 작업판(`블로그편집국`), 구글 시트(`발행관리`), 블로그 스케줄 실행 기록,
네이버 블로그 통계(`조회수 순위`)에서 옮겨 적은 값만 담고 런타임에 API를 호출하지 않습니다.
조회수는 네이버가 글별 누적치를 따로 주지 않아 기간별 순위 값(주간 11/09~11/15 + 일간 11/16~11/20)을
글별로 합산했고, 합산 기준 시각을 화면에 함께 적었습니다.
큐·부이·뮤즈·키링의 상태는 노션 `담당AI` · `상태` · 최종 수정 시각에서 파생한 값이며,
실시간 프로세스 표시가 아닙니다.

## 갱신 방법

데이터가 바뀌면 `index.html`을 새로 생성해 `main` 브랜치에 커밋하면 몇 십 초 안에 Pages에 반영됩니다.

## 개인정보

연락처·이메일·주소·계정 정보 등 개인 식별 정보는 넣지 않았습니다. 블로그 작업 데이터만 있습니다.
